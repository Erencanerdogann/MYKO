## ⚡ HIZLI ÖZET

### Bizim oyunumuz nedir?

**MalaysiaKO (Bynoisee)** — Knight Online private server.
- **Base client:** v2369 (modern HD grafik, ~2010-2014 dönemi exe)
- **Patch giydirme:** v1098 (eski-okul MYKO içerik mantığı, ~2005-2006 dönemi)
- **Sonuç:** Modern grafik + nostaljik 1098 oynanış (lvl cap 72, Bifrost yok, Ardream yok)
- **Lansman:** 08 Mayıs 2026 ("Valor")
- **Tip:** MYKO tarzı (Light/Medium Farm PvP)

### KO nedir?

- **Yapımcı:** MGAME Corporation (Kore) + Noah System
- **Release:** KR 15 Temmuz 2002 / NA 17 Ağustos 2004 (K2 Network, sonra NTT Game)
- **Tip:** MMORPG, PvP odaklı, 2 ırk savaşı (Karus vs El Morad)
- **2007 zirve:** 4M+ kayıtlı kullanıcı
- **Bugün (2026):** Steam KO Cypher/Adonis (NTT), private server sahnesi çok aktif

### 1098 vs 2369 Karşılaştırma

| Özellik | 1098 | 2369 |
|---------|------|------|
| Yıl | ~2005-2006 | ~2010-2014 |
| Level cap | 70-72 | 80-83 |
| Bifrost/Ardream | ❌ Yok | ✅ Var |
| Dragon Cave | ❌ Yok | ✅ Var |
| Accessory upgrade | +1 | +9 (+20 custom) |
| Weapon upgrade | +8 | +9 (+20 custom) |
| UI | Klasik | Reign of Fire Drake (modern) |
| AntiCheat | KiraGuard | CurseACS / nProtect |
| TR popülerliği | Çok yüksek | Yüksek |

**Bizim hibrit:** 2369 client (HD grafik + AntiHack) + 1098 patch (nostalji + cap 72 + sade içerik). Türk sahnesinde **standart yaklaşım**, **atipik DEĞİL**.
